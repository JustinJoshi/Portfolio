date: 2026-02-06

Worked with cursor to build out my application.
- Initially tried getting cursor to one-shot the project. Ran into errors with that process, a few being
	- AI not completing some of the work
	- Almost done, but buggy features.
	- My own understanding of what it had created was not good!
		- Allowing cursor to create a complex application without much help was a great exercise in seeing what these models are capable of. But it came with some shortcomings such as hallucination, and increasing complexity!

That's when I realized the importance of developing iteratively! Building out features one by one helped me
- Understand the output of the LLM
- Test code right when it was created
- Ask the model to make improvements where I saw fit

Overall cursor is VERY impressive and I had a lot of fun troubleshooting the project development last night, feel like I gained a lot of deep insight into how these models function and how to make great use of them! I'm feeling great and excited to keep exploring what possible!
